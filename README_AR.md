# AB OPEN WORLD — مشروع Android Native (Godot 4.4.1)

هذه حزمة مشروع لعبة ثلاثية الأبعاد Native مبنية بـ Godot 4.4.1 وGDScript. التطبيق لا يستخدم WebView ولا Three.js ولا CDN. إعداد Android لا يطلب صلاحية إنترنت، لذلك محتوى اللعبة المضمّن يعمل دون اتصال بعد تثبيت APK.

> **مهم بخصوص ملفات المجسمات:** ملفات GLB الأصلية الخاصة بك لم تكن مرفقة في المحادثة، لذلك لم أضع ملفات بديلة مزيفة مكانها. مجلد `models/` جاهز، وأنت تضيف ملفاتك الفعلية إليه قبل بناء APK. إذا لم تضف `Man.glb` تعمل شخصية بديلة حتى تضيف مجسمك.

## محتويات المشروع

- `project.godot` — إعدادات المشروع والاتجاه الأفقي ومحرك Compatibility.
- `scenes/Main.tscn` — المشهد الرئيسي.
- `scripts/main.gd` — إنشاء العالم والواجهة وربط الأنظمة.
- `scripts/player.gd` — حركة الشخصية، القفز، الجري، الكاميرا، الأنيميشن، ودخول المركبة.
- `scripts/world_manager.gd` — الأرض، السماء، دورة اليوم، الشمس، الضباب، الطرق، الأرصفة، الأشجار، وحدود العالم.
- `scripts/vehicle.gd` — مركبة قابلة للقيادة مع تصادم.
- `scripts/asset_manager.gd` — تحميل GLB/GLTF المضمّن والمستورد محلياً، حفظ الأصول، تصادم المجسمات، واكتشاف أسماء المرايا.
- `scripts/pose_editor.gd` — اختيار عظام Skeleton3D، نقاط عظام ثلاثية الأبعاد، محاور XYZ، تعديل الدوران/الموضع، وحفظ الوضعيات.
- `scripts/save_system.gd` — حفظ العالم والشخصية والكاميرا والمركبة والأجسام المستوردة محلياً.
- `.github/workflows/android.yml` — بناء APK تلقائياً من GitHub Actions.
- `reference/The_Game_Original.html` — نسخة HTML الأصلية مرجعاً للمقارنة؛ لا يتم تشغيلها داخل التطبيق.

## إضافة ملفاتك قبل البناء

ضع ملفاتك في مجلد `models/`:

```text
models/Man.glb
models/Girl.glb
models/Home.glb
models/Car.glb
```

- `Man.glb`: يصبح مجسم اللاعب، ويُضبط حجمه تلقائياً تقريباً إلى ارتفاع 1.8 متر.
- `Girl.glb`: مجسم إضافي.
- `Home.glb`: مبنى/منزل مع توليد تصادمات تقريبية بصناديق حدود للمجسمات الثابتة؛ جودة التصادم تعتمد على تقسيم مجسم GLB إلى أجزاء مناسبة.
- `Car.glb`: يستبدل الشكل الافتراضي للسيارة التي تقودها.
- يمكنك إضافة أي أسماء أخرى؛ GitHub Actions ينشئ `models/catalog.json` تلقائياً من ملفات GLB/GLTF الموجودة، فتظهر في قائمة Add.

**الأفضل GLB** لأنه يضم المجسم والخامات والصور في ملف واحد. إذا استخدمت GLTF منفصلاً، ارفع ملف `.gltf` وكل ملفات `.bin` والصور التابعة مع الحفاظ على نفس أسماء الملفات والمسارات النسبية.

## رفع المشروع إلى GitHub من الهاتف

1. نزّل ZIP وفك ضغطه على الهاتف.
2. أنشئ مستودعاً جديداً على GitHub.
3. افتح المجلد الذي يحتوي `project.godot` و`.github` و`scripts`، وارفع **محتويات هذا المجلد** إلى جذر المستودع، وليس ملف ZIP وحده. تأكد أن `.github/workflows/android.yml` موجود في جذر المستودع بهذا المسار بالضبط.
4. ضع ملفات GLB داخل `models/` ثم ارفعها مع المشروع.
5. افتح تبويب **Actions**. شغّل `Build AB OPEN WORLD Android APK` من `Run workflow`، أو اتركه يبدأ تلقائياً بعد Push إلى `main` أو `master`.
6. عند نجاح التشغيل افتح صفحة الـ Workflow، ثم قسم **Artifacts** ونزّل `AB-OPEN-WORLD-ANDROID-APK`.
7. فك ضغط Artifact إذا نُزّل كملف ZIP، ثم ثبّت `AB_Open_World.apk` على هاتف Android.

البناء يستخدم Godot 4.4.1 وJava 17 وAndroid SDK. يتم إنشاء مفتاح Debug مؤقت داخل GitHub Actions؛ هذا APK للتجربة والتثبيت الشخصي، وليس إعداد توقيع إصدار متجر Google Play.

## التحكم داخل اللعبة

- D-pad للحركة في الاتجاهات الأربعة.
- Jump للقفز، وRun للتبديل بين المشي والجري.
- اسحب بإصبع واحد في مساحة العالم لتدوير كاميرا الشخص الثالث، واستخدم إصبعين للتقريب/الإبعاد (Pinch). عند الاختبار على الكمبيوتر استخدم عجلة الماوس للزووم.
- اقترب من السيارة واضغط Drive للدخول، واضغط مرة أخرى للخروج.
- Add لإضافة المجسمات أو استيرادها من الجهاز؛ اختر أي مجسم من قائمة Add نفسها ثم حرّكه أو كبّره أو دوّره أو احذفه. لا يتم اختيار المجسمات بلمس العالم لتجنب الاختيار العرضي.
- World لضبط الوقت واتجاه الشمس وتشبع السماء والضباب والإضاءة والأرض والكاميرا وحجم الشخصية وإضاءتها المحلية.
- Anim لاستعراض مقاطع AnimationPlayer وتشغيلها، مع اختصارات Punch وSit to stand وStand to sit إذا كانت هذه المقاطع موجودة في GLB.
- Control و3D لفتح محرر Skeleton3D واختيار العظام وتعديلها وحفظ الوضعيات.

## حفظ البيانات والاستيراد المحلي

- يتم حفظ العالم والشخصية وموقعها ودورانها وحجمها وزاوية الكاميرا وبعدها والمركبة والأجسام المستوردة وإعدادات الإضاءة محلياً في مساحة التطبيق.
- يوجد حفظ تلقائي دوري كل 45 ثانية أثناء اللعب، بالإضافة إلى زر Save world والحفظ عند إيقاف التطبيق/تعليقه.
- ملفات GLB/GLTF المستوردة تُنسخ إلى `user://models` لتظل متاحة بعد إغلاق اللعبة وإعادة فتحها.
- زر `Scan app local models` يعيد فحص مجلد الملفات المحلية داخل التطبيق.
- منتقي الملفات في Android قد يختلف سلوكه حسب إصدار النظام ونسخة Godot وصلاحيات الوصول. لذلك تضمين ملفات GLB داخل `models/` قبل البناء هو المسار الأكثر موثوقية للعمل أوفلاين.

## إعدادات الأداء والتوافق

- تم اختيار Compatibility Renderer ليتوافق مع نطاق أوسع من أجهزة Android.
- ظلال الشمس معطلة افتراضياً، وإضاءات الشخصية محلية على طبقة عرض منفصلة.
- التصادمات الثابتة تُنشأ عند تحميل الأصول، مع حد أقصى لعدد الشبكات التي تُنشأ لها أشكال تصادم.
- لا أستطيع ضمان عدم حدوث تهنيج على كل هاتف؛ حجم GLB، وعدد المضلعات، ودقة الصور، والذاكرة المتاحة عوامل مؤثرة. اختبر APK على جهازك مع ملفاتك الفعلية.

## التحقق من البناء

بيئة إعداد هذه الحزمة لا تحتوي على محرر Godot أو Android SDK لتشغيل اللعبة أو تصدير APK محلياً. لذلك أضفت خطوة استيراد/تحقق داخل GitHub Actions قبل التصدير؛ نجاح الـ Workflow هو اختبار البناء الفعلي. لا تعتبر APK جاهزاً قبل أن ينتهي الـ Workflow بحالة Success.
